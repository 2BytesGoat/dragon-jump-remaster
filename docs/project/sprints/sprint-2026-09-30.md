# Sprint 2026-09-30 — Editor Foundation + World Reorganization

## Sprint goal

Stand up the in-game level editor and reorganize the campaign into the 5-world structure. This is Sprint 1 of 3 toward the **Nov 30 EA build milestone** (editor + Workshop + 25–30 levels → Dec 2026 EA launch).

## Milestone

- Milestone: EA build complete (Phase 1)
- Target date of milestone: **2026-11-30** (EA launch follows in Dec 2026)
- This sprint's contribution: working editor core + world structure in place

## Capacity

- Hours budget this sprint: ~12–18h
- IRL load note: Post-pipeline (Aug 31), September away may have been in play — adjust as reality allows. October game jam month will reduce capacity; plan around it.
- Slack: ~3–6h for editor architecture surprises

## Deliverables

| Backlog # | Task | Est. (h) | Notes |
|-----------|------|----------|-------|
| #83 | Build the in-game level editor (core) | ~10 | Symbol-based format; reuses in-engine editor fixes from #49. Start with the core: tile placement grid, test/play button, save/load level codes. | 
| #85 | Organize existing 17 levels into 5-world structure | ~2 | Map 1-1..1-17 into worlds; identify gaps per world. World 1 = tutorial mechanics; later worlds escalate. |

## Definition of done

- [ ] Editor can place/erase tiles from the symbol set (W, E, P, Q, Y, O, B, J, M)
- [ ] Editor can test the current level in-place (play → death/reset → back to editor)
- [ ] Editor saves/loads level codes in the RLE format
- [ ] Campaign is organized into 5 named worlds; existing 17 levels are assigned
- [ ] Per-world gap list exists (how many levels each world needs to hit 25–30 by Nov 30)
- [ ] Input hint overlay added for casual players
- [ ] No regression: campaign still playable, arcade loop still works

# Sprint 2026-11-30 — EA Build Complete + Store Prep

## Sprint goal

Finish the campaign at 25–30 levels, surface the ML mode, and update the Steam store page so the build is launch-ready for **Dec 2026 Early Access**. This is Sprint 3 of 3 toward the EA build milestone.

## Milestone

- Milestone: EA build complete (Phase 1)
- Target date of milestone: **2026-11-30** — EA launch follows in December
- This sprint's contribution: launch-ready build + store page

## Capacity

- Hours budget this sprint: ~12–18h
- IRL load note: Post-jam month; push to finish. The Dec EA launch is the payoff.
- Slack: ~3–6h for store page back-and-forth (Steam review)

## Definition of done

- [ ] Campaign has 25–30 levels across 5 worlds
- [ ] ML mode is accessible from a visible menu entry and works on any level
- [ ] Steam store page is live with EA description, screenshots, trailer, and tags
- [ ] EA store description is honest about scope (levels + editor now; world arcade + challenges at 1.0)
- [ ] Dead multiplayer/crown/tag code removed or hidden
- [ ] Build passes CI web export + smoke test
- [ ] Price set to $9.99 for EA

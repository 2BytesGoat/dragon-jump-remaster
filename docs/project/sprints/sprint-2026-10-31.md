# Sprint 2026-10-31 — Workshop + Arcade + Boss Levels

## Sprint goal

Wire Steam Workshop into the editor, build the world selection screen and basic arcade mode, and design the first boss levels. This is Sprint 2 of 3 toward the **Nov 30 EA build milestone**.

## Milestone

- Milestone: EA build complete (Phase 1)
- Target date of milestone: **2026-11-30** (EA launch follows in Dec 2026)
- This sprint's contribution: Workshop publish/subscribe + playable world structure

## Capacity

- Hours budget this sprint: ~10–15h
- IRL load note: October is the game jam month — capacity may be tight. The editor core from Sprint 1 must hold.
- Slack: ~3–5h for Workshop API integration surprises

## Deliverables

| Backlog # | Task | Est. (h) | Notes |
|-----------|------|----------|-------|
| #84 | Steam Workshop integration | ~8 | Publish/subscribe community levels. Depends on editor core (#83). Includes Workshop UI (browse, download, play). |
| #88 | World selection screen | ~2 | Shows unlocked worlds, best score/medal/rank; locked worlds grayed out with theme preview. |
| #89 | Basic arcade mode with local leaderboard | ~3 | Wire existing `ArcadeDirector` + end_screen; local top-10. |
| #87 | Boss level design (first 2 worlds) | ~2 | Longer, harder, tests all world mechanics; no powerup pickups inside. |

Total: ~15h. Tight against the 10–15h budget — first cut if slipping is #87 (boss levels).

> **Note:** If #84 (Workshop) proves risky, the EA launch still works with editor + levels and Workshop added as a fast-follow in Dec. But the plan is Workshop day 1.

## Definition of done

- [ ] Player can publish a level to Workshop from the editor
- [ ] Player can browse and download community levels from Workshop
- [ ] Downloaded levels appear in a "Community" level list and are playable
- [ ] World selection screen works (unlock logic, per-world best score)
- [ ] Basic arcade mode: pick a world → play with 3 lives → local top-10
- [ ] First 2 boss levels exist and are beatable
- [ ] No regression: campaign playable, editor works end-to-end

- Daily/weekly challenge system (#98–99) — Phase 3 (1.0 build)
- Steam leaderboards (#102) — Phase 3
- Full SFX/music/UI polish (#103–104) — Phase 3

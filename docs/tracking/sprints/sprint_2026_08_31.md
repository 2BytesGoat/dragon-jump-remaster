# Sprint 2026-08-31 — Emulation Station + Documentation + Reproducibility Test

## Sprint goal

Install Emulation Station on the modded Switch, configure it to launch the web build, test the full cabinet boot flow, and write reproducible documentation that another jam participant can follow. This is Sprint 2 of 2 toward the Aug 31 pipeline milestone.

## Milestone

- Milestone: Reproducible arcade pipeline (Phase 3)
- Target date of milestone: **2026-08-31** (hard deadline — this sprint ends on the deadline)
- This sprint's contribution: ES setup + cabinet test + documentation + reproducibility test

## Capacity

- Hours budget this sprint: ~10–15h (crunch mode — this is the finish line)
- IRL load note: Last push before September away. The Aug 31 cabinet test is the one non-negotiable.
- Slack: ~0–5h. If Sprint 1 slipped, this sprint's scope must shrink (docs and second-dev test are first cuts).

## Definition of done

- [ ] Emulation Station is installed and running on the modded Switch
- [ ] Scraper (#82) fetches the latest web build from itch.io and places it where ES can launch it
- [ ] Emulation Station launches the fetched web build successfully
- [ ] Full boot flow works: power on → ES → game → play → exit → ES (repeated 3x without crash)
- [ ] A document exists that another dev can follow to replicate the whole pipeline
- [ ] (Stretch) A second dev has successfully followed the docs from scratch
- [ ] Arcade build artifact is produced and checksummed via CI
- [ ] Arcade loop survives a smoke test (start → play → die/finish → game-over → retry → exit)
